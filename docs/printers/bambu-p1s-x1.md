# Bambu Lab P1S / X1 のプロファイル

公共の工房で使う FDM 機(Bambu Lab P1S と X1)の、設計に効く値と、公差の実測値。施設の名前・料金・予約などは、このリポジトリには書かない(公開できない私的な記録の側に置く)。

**確からしさ**: 「確認済み」は 2026-10-16 に、Bambu Studio 2.8.2.61(Flathub)の同梱プリセットを自分で読んだもの。「未確認」は読めていない。

## 機種

| 項目 | 値 | 確からしさ |
|---|---|---|
| 方式 | FFF(P1S は 4 色、X1 は 8 色まで、どちらも高速機) | 工房の料金表の記載(施設側の資料) |
| ノズル径(プリセット) | 0.4 mm | 確認済み(`Bambu Lab P1S 0.4 nozzle` / `X1 0.4 nozzle` の `nozzle_diameter`) |
| ノズル径(工房の実機) | 未確認 | 未確認 |
| 造形範囲 XY | 256 × 256 mm | 確認済み(共通プリセット `fdm_bbl_3dp_001_common` の `printable_area`) |
| 造形範囲 Z | 256 mm | 未確認(同梱のプリセットに高さの記載が無く、公式仕様を読み戻していない) |

`lab check` の造形範囲は、既定の `--printer bambu-p1s-x1` で 256 mm 角(Z も 256 mm と仮定)にしてある。除外域は考慮していない(スライサーが配置を決める)。

## 材料と設定の前提

- 材料: PLA(Bambu PLA Basic の想定)
- 工程: 0.20 mm Standard(層の高さ 0.2 mm)。プリセット無しの CLI では、壁 2 周・充填 20% だった(確認済み)
- 設計の目安(出典: [Digital Fabrication Lab, Design the clearance and tolerance](https://wiki.cci.arts.ac.uk/books/digital-fabrication-lab/page/design-the-clearance-and-tolerance-yC5)、取得 2026-10-16): Bambu の機種での片側の隙間は 0〜0.2 mm の範囲で、はめ合いの種類で選ぶ。重要なはめ合いは、先に小さな見本を刷って試す

## 公差の実測値

`parts/plate_pico_v2.py` のプレートは、ケースの本体 1 個と、袖と外壁の隙間 `fit` の違う蓋 3 枚を載せる。蓋の板の外側の面に、点が 1 / 2 / 3 個彫ってある(= `fit` 0.2 / 0.3 / 0.4 mm)。蓋を止める強さ `snap_engage`(食い込み、既定 0.2 mm)は 3 枚で共通なので、比べるのは、袖が壁に沿う余裕だけ。

はめ合いの体験は、本体の壁のたわみと蓋の位置決めで変わる。1 周目に載せた、スナップだけを切り出した小さな試験片は、位置決めが片側にしか無く、ケースを閉める体験を再現しなかったので、廃止した。

### 1 周目(2026-10-24、`fit` 0.2 mm、PLA)の結果

- ケースは閉じ、Pico も収まった。
- 基板の面に沿う向きで、Pico と内壁の隙間(設計 0.3 mm)と、蓋の袖と外壁の隙間(設計 0.2 mm)が小さかった(余裕はわずか)。取付穴とピン(設計 0.15 mm)は、ちょうどよかった。
- ノギスでの実測(2026-10-31)は、下の表。内壁の間は設計より 0.18〜0.24 mm、壁の外側は 0.06〜0.10 mm、袖の内側は 0.05〜0.26 mm 小さかった。
- USB と BOOTSEL(2026-10-31): 蓋を閉めた状態で、付属品の micro USB ケーブルが Pico の奥まで入った。蓋の穴から爪楊枝で BOOTSEL ボタンに届き、カチッと手応えがあった。穴の位置のずれは無し(`bootsel_x` / `bootsel_y` の既定値のまま)。

内側の輪郭(壁の内側、袖の内側)が設計より狭く出ることは、冷えて縮むと寸法が小さくなり、穴が細ると書く資料と合う(出典: [Bambu Lab Wiki, 3D Prints Shrinkage](https://wiki.bambulab.com/en/knowledge-sharing/3d-prints-shrinkage)、取得 2026-10-24)。外側の輪郭(壁の外側)は、設計より太くは出ず、0.06〜0.10 mm 小さく出た(下の表。ピンは測っていない)。壁の厚みに直すと、実測は長い向き約 1.67 mm、短い向き約 1.66 mm(設計 1.6 mm)で、内側の縮みのほうが外側より大きい。

### 寸法の実測

刷った日・機種(P1S / X1)・材料・ノズル径: 2026-10-24。機種は P1S(予約を P1S で申請した。刷った機そのものの確認は取れていない)。材料は PLA。ノズル径は未確認(工房の実機。プリセットは 0.4 mm)。蓋は `fit` 0.2 mm のもの。測った日は 2026-10-31(室温は記録していない)。

ノギスで、高さの中ほどを測る(下の 1 層は広がりやすい)。各箇所で、長い向き × 短い向きを測り、毎回爪を当て直す。ノギスの最大許容誤差は ±0.03 mm(表示の端数 ±0.01 mm を含まない。[ノギスの仕様と出典](../workflow.md#測る道具))。

| 箇所 | 設計値(mm) | 実測(mm) | ずれ(実測 − 設計) |
|---|---|---|---|
| 本体の内寸(内壁の間) | 51.6 × 21.6 | 51.36 × 21.42 | −0.24 × −0.18 |
| 本体の外寸 | 54.8 × 24.8 | 54.70 × 24.74 | −0.10 × −0.06 |
| 蓋の袖の内寸(`fit` 0.2 の蓋。突起を避け、袖の根元寄りで測る) | 55.2 × 25.2 | 54.94 × 25.15 | −0.26 × −0.05 |

測った値(mm)。代表値は、ばらつきが小さい箇所は平均、本体の外寸の長い向きは中央値。

| 箇所と向き | 測った値 | 代表値 |
|---|---|---|
| 本体の内寸、長い向き | 51.36 / 51.33 / 51.38 | 51.357(平均) |
| 本体の内寸、短い向き | 21.40 / 21.42 / 21.44 | 21.420(平均) |
| 本体の外寸、長い向き | 54.68 / 54.86 / 54.72 / 54.69 / 54.73 / 54.68 / 54.85 / 54.68 | 54.705(中央値) |
| 本体の外寸、短い向き | 24.74 / 24.75 / 24.74 | 24.743(平均) |
| 蓋の袖の内寸、長い向き | 54.92 / 54.94 / 54.95 / 54.93 / 54.96 | 54.940(平均) |
| 蓋の袖の内寸、短い向き | 25.14 / 25.15 / 25.16 | 25.150(平均) |

- **本体の外寸の長い向き**: 8 回中 2 回(54.86、54.85)が、ほかの 6 回(54.68〜54.73)より約 0.15 mm 高く出た。原因は未確認(爪の傾き、別の場所に当たった、など)。高い 2 回を捨てず、中央値を代表値にした。高い 2 回を除いた 6 回の平均は 54.697 で、ほぼ同じ。
- **蓋の袖の内寸の長い向き**: 最初に測った 5 回(54.97 / 54.85 / 54.55 / 54.63 / 54.51)は、ばらつきが 0.46 mm あり、不採用。原因は未確認(長い向きの片方の壁にある USB の切り欠きに爪がかかった、薄い壁(1.0 mm)が爪の押しでたわんだ、爪の傾き、など)。切り欠きを避けた位置(短い向きの中央から片側へ約 9 mm)で、壁に触れる程度の力で測り直した 5 回(ばらつき 0.04 mm)を採用した。
- **蓋の袖の内寸の向きによる差**: 長い向きは −0.26 mm、短い向きは −0.05 mm。原因は未確認。
- **爪の傾き**: 内寸を測るとき、内側用の爪が壁に対して斜めになっていないかは、目視でしか判断できなかった。揺らして最小で止める読み方は、そこが真値になる根拠が無いので採らなかった(毎回同じ位置で当て直し、複数回測って、ばらつきを記録した)。

### 蓋 3 枚の判定

本体に蓋を、点の数 1 / 2 / 3 の順にかぶせる。判定は、最初にはめたときの感触で書く(繰り返すと変わりうる)。

- 入る: 蓋を本体の上に押し込んで、カチッとはまる。
- 止まる: 閉めた状態で振っても外れない。
- 外せる: 割れずに外せる。

|---|---|---|---|---|---|---|
| 1 | 0.2 | | | | | |
| 2 | 0.3 | | | | | |
| 3 | 0.4 | | | | | |

- 採用する `fit`:
- ケースに反映したか(`parts/pico_case.py` の `Dims.fit` の既定値):

割れる・固すぎるときは、`snap_engage` を下げるか、腕の長さ(`skirt_h`)を伸ばす。緩すぎて止まらないときは、`snap_engage` を上げる。開け閉めできる回数の見込みは、`parts/pico_case.py` の docstring に書いた(未検証)。

### 組み合わせの単位

寸法のずれは、機種だけでなく、ノズル径・造形の設定・材料の製品でも変わる。Bambu Studio 2.8.2.61 の同梱プリセットでは、縮み率(`filament_shrink`)と押し出し量の倍率(`filament_flow_ratio`)が材料の設定に、内側・外側の輪郭の寸法補正(`xy_hole_compensation` / `xy_contour_compensation`)が造形の設定にある。補正の既定値は、どちらも 0(`fdm_process_common.json`、2026-10-24 に読んだ)。補正値は、ノギスで測った実測から決めて、機種の表(`src/lab/printers.py` の `BambuCompensation`)に入れる([ADR-30](../adr/30-xy-compensation-in-slicer.md))。向きは、`xy_hole_compensation` の正の値で穴が大きくなり、`xy_contour_compensation` の正の値で外形が大きくなる(Bambu Studio v02.08.02.61、`PrintConfig.cpp` 6335〜6353 行)。内側が設計より狭いなら `xy_hole` を正に、外側が設計より太いなら `xy_contour` を負にする。穴の大きさや向きでずれが変わること、同じ機種でも 1 台ごとに少し違うことは、一般論としては知られているが、一次資料では確かめていない(未確認)。そのため、実測の表には、刷った機種(P1S か X1 か)を必ず記録する。

## ツールの確認(スライサー)

- Bambu Studio 2.8.2.61 の CLI で、書き出した 3MF のスライスが通る(終了コード 0、警告なし、オブジェクトは部品の数と一致)。
- 同梱のプリセット(P1S 0.4 nozzle、0.20mm Standard @BBL X1C、Bambu PLA Basic @BBL P1S 0.4 nozzle)を、継承を解決して渡すと、プレート 1 枚(`plate_pico_v2`、本体 1 個と蓋 3 枚)の予測時間は 28 分、重さは 13.61 g だった(`uv run lab slice plate_pico_v2`、Bambu Studio 2.8.2.61、2026-10-24)。filament の使用量 4.49 m と密度 1.26 からの検算(13.61 g)と一致する。1 周目のプレート(`plate_pico_v1`、試験片入りで 8 部品、削除済み)は約 24 分、9.90 g だった(2026-10-16。使用量 3.27 m からの検算で 9.91 g)。工房の機械の実際の設定での値とは限らない。
- 継承を解決せずに渡すと、使用量が 0.00 g になり、予測時間は約 19 分になる(以前の記録を再現した)。CLI が `inherits` を解決せず、`filament_density` が親のプリセットにしか無いため。`lab slice` が解決してから渡す。詳細は `docs/research/code-cad-stacks-2026-10.md`。
- 導入は dotfiles の `home/modules/flatpak.nix`(`tarotene/dotfiles#811`)で宣言し、`hms` で適用した。flatpak 版の CLI はホームの外のファイルを読めない。
